# DynamoCivil

Dynamo scripts (.dyn) for Civil 3D.

## Folders

Alignments - alignment and profile scripts
Corridors - corridor scripts
Surfaces - surface scripts
Utilities - general helpers

## Use on a PC

First time:

    git clone https://github.com/PomadaBoy/DynamoCivil.git "D:\GitHub\DynamoCivil" --branch=main

Update:

    git -C "D:\GitHub\DynamoCivil" pull

In Civil 3D, point Dynamo Player at D:\GitHub\DynamoCivil.
